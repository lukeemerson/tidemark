3D monitor mockups

Five ways to put the Monitor TUI in 3D. Each sketch is a still frame in the same palette. Evaluation and picks are in ../EVALUATION.md.

A

B

Silicon floor

The M2 Pro as a floorplan board. Each E core, P core, GPU core and memory block is a tile that extrudes with load and glows with temperature.

   ┌──────────────────────── Apple M2 Pro ─────────────────────────┐
   │  E-cluster 2424 MHz        P-cluster 3504 MHz                 │
   │  ▆ ▃ ▂ ▁                    ▃ ▂ ▁ ▇ ▆ ▅                        │
   │  E1 E2 E3 E4                P1 P2 P3 P4 P5 P6                 │
   │  ┌─ GPU 16 cores ────────────────┐   ┌─ unified memory ─────┐ │
   │  │ ▁ ▁ ▁ ▁ ▁ ▁ ▁ ▁ ▂ ▁ ▁ ▁ ▁ ▁ ▁ ▁ │   │ ████████████████···· │ │
   │  └───────────────────────────────┘   └──────────────────────┘ │
   └─ tilt: 35° isometric · temp tints the board 66° ───────────────────┘
      hover a block → TUI tooltip:  ┏━ P4 ━━━━━━┓
                                    ┃ 68%  3504 MHz ┃
  • Reads as: where on the chip the work is happening, which a flat list of cores can't show.
  • Honesty note: the layout is a schematic, not the real die photo.
C

History terrain

The braille graphs turned into a landscape: cores run across, the last 90 seconds run back into depth, and height is load.

                                      ← now          90 s ago →
          P6 ▁▂▂▃▅▆▃▂▁▁▁▂▂▁
        P5 ▁▂▃▃▂▂▁▁▁▆█▅▂▁             ridge lines per core, level-coloured
      P4 ▂▃▅▆▇▆▃▂▂▃▃▂▁▁               the front ridge is the current sample
    ...                                   scrub bar:  ◀ ▮▮▮▮▮▮▮▮▯▯▯▯ ▶  t−34s
  E1 ▃▄▃▃▂▂▃▃▂▂▂▃▃▂
  ────────────────────────── floor grid in dim, 10 s per line
  • Interaction: orbit, scrub the time cursor, click a ridge to isolate that core, toggle cpu / gpu / power layers.
D

Panel constellation

Every Box panel floats as its own slab on an arc around the camera. Panels lean toward you as their load rises.

      ┏━ cpu ━━┓        ┏━ gpu ━━┓        ┏━ power ━┓
        ╲ tilt 12°      │ flat │           ╱ tilt 20°
   ┏━ cores ━━━━┓                         ┏━ memory ━━┓
                      ⊙ camera
   ┏━ processes ━━━━━━━━━━━━┓      ┏━ cloudflare ━━┓
  • Risk: it's a dashboard spread out in space. Depth adds travel time without adding information.
E

Terminal-native 3D
