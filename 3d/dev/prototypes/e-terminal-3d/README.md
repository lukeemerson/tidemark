# e · terminal-native 3d
Run: `./monitor3d.py` (replays ../../../shared/samples.json at 1 Hz) or `./monitor3d.py --live` (mactop; falls back to replay).
Keys: `←/→` rotate · `↑/↓` tilt · `space` pause · `a` auto-spin · `r` ratty · `q` quit.
In Ratty (auto-detected via the RGP `s` query) each core becomes a placed `cube.obj`; `--force-ratty` skips detection.
Needs a terminal of at least 60×20; smaller shows a dim resize note.
