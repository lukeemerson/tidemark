One row of 8-level block characters `▁▂▃▄▅▆▇█` showing recent history, newest on the right.

- Use inside tiles and for cloudflare run history.
- You supply: values, width, max. Returns plain text, so colour the segment yourself.
- Columns with no sample yet stay blank, so a short history sits at the right edge.
- Zero still draws `▁`. Use `BrailleGraph` when you have room for more than one row.
